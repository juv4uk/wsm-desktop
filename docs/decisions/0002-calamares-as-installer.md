# ADR 0002: Calamares як графічний інсталятор

<!-- SPDX-License-Identifier: LicenseRef-Volnist -->

- Статус: прийнято як архітектурний напрямок
- Дата: 2026-11-25

## Контекст

Користувачам потрібен графічний інсталятор. Власний інсталятор з нуля відволікатиме ресурси від інтеграції системи та збільшить кількість коду, який має працювати з правами адміністратора.

## Рішення

Використовувати Calamares як UI та workflow engine. Для інтеграції з Guix створити власний WSM deployment adapter.

## Обмеження

Calamares не має вважатися готовим Guix backend. Сумісність generic users, bootloader та filesystem modules повинна бути підтверджена окремо.

Для початкової схеми Guix System має бути єдиним власником bootloader installation. Подвійне встановлення завантажувача через Calamares і Guix заборонене.

## Перегляд рішення

Після M2, якщо Calamares або його залежності неможливо надійно зібрати в Guix live environment, рішення слід переглянути на основі конкретних даних, а не припущень.
