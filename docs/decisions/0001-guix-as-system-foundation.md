# ADR 0001: GNU Guix System як системна основа

<!-- SPDX-License-Identifier: LicenseRef-Volnist -->

- Статус: прийнято
- Дата: 2026-11-25

## Контекст

WSM Desktop потрібна система, яку можна декларативно описувати, переглядати, відтворювати та оновлювати. Створення власного пакетного менеджера та init system не є метою першого етапу.

## Рішення

Використовувати GNU Guix System як базову операційну систему та пакетне середовище.

WSM підтримує власні конфігурації, модулі, пакети та інструменти інтеграції, але не створює форк Guix без окремої технічної необхідності.

## Наслідки

- Ми залежимо від архітектури Guix та його каналів.
- Потрібно вивчити Scheme-конфігурацію operating-system.
- Релізні збірки повинні фіксувати точні ревізії каналів.
- Відмінності WSM мають бути зосереджені на досвіді користувача, інтеграції та профілях.
