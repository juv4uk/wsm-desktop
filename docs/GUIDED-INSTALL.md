# Покроковий вибір диска в консолі

<!-- SPDX-License-Identifier: LicenseRef-Volnist -->

- Статус: **read-only preview; на реальному диску не запускався**
- Код: wsm_install/guided.py
- Тести: tests/test_guided.py

## Запуск

Команда: wsm-install --preflight --dry-run --report hw.json --backend guix --guided

## Як працює

Покроковий режим показує апаратний звіт, перелік цілих дисків, дає вибрати
ціль і firmware (UEFI типово). Потім користувач повторно вводить шлях диска,
щоб підтвердити **лише ціль, для якої будується preview**.

Після вибору режим викликає один preview callback. Він показує план і повертає
код результату. Якщо planner завершується помилкою, guided mode повертає її
код і не друкує повідомлення про успішне завершення preview.

## Межі

- Немає запитання «Install now?», слова install як підтвердження або окремого install callback.
- Підтвердження шляху не є дозволом на запис.
- --execute відхиляється на рівні CLI до запуску guided flow.
- Спільний executor відхиляє dry_run=False; жодні sgdisk, mkfs, mount чи guix system init у цьому шляху не запускаються.

## Що ще не перевірено

- Запуск на реальному диску чи фізичному обладнанні.
- Вибір файлової системи/точки монтування у flow.
- Відновлення після помилки майбутнього APPLY. APPLY наразі вимкнено.
