# Псевдографічний інсталятор

<!-- SPDX-License-Identifier: LicenseRef-Volnist -->

- Статус: **реалізовано як read-only preview; запуск у справжньому терміналі ще не перевірявся**
- Код: wsm_install/tui.py
- Тести: tests/test_tui.py

## Три входи, один бекенд

| Вхід | Для кого | Дозволена дія |
| --- | --- | --- |
| --guided | послідовна лінія, скрипт, простий термінал | вибір цілі та preview |
| --tui | екран і клавіатура без робочого столу | вибір цілі та preview |
| Calamares | машина, яка підтримує Qt | той самий preview через jobmodule |

Усі frontend-и використовують спільні partition.py, install_steps.py та executor.py.
Жоден із них не має власного шляху до дискового запису.

## Як виглядає вибір

Вибір диска відображається в рамці з навігацією стрілками або j/k. Enter обирає
диск, q завершує роботу. Далі обирається firmware (UEFI/BIOS), а шлях диска
вводиться повторно лише для підтвердження того, **для якої цілі показати preview**.

Після цього TUI викликає тільки preview callback і показує, що APPLY вимкнено.

## Межа безпеки

- Немає екрана «Enter to install», install callback або повідомлення «Installation finished».
- Якщо planner повернув ненульовий код, TUI показує Preview failed, а не Preview ready.
- Введений шлях підтверджує вибір цілі для preview. Це не destructive consent і не дозвіл на зміну диска.
- CLI відхиляє --execute до переходу в TUI; спільний executor так само відхиляє dry_run=False.

## Чому не curses

curses вбудований у стандартну бібліотеку, але додає керування terminal capabilities
та глобальний screen state. Тут екран — це список рядків, а читач клавіш і render
interface ін'єктовані; це спрощує тести без справжнього термінала.

## Відкат на консоль

Якщо stdin або stdout не є TTY, --tui не малює зламаний екран: він повідомляє
про це в stderr і переходить на --guided.

## Що ще не перевірено

- Запуск у справжньому TTY/serial terminal та поведінка вузького вікна.
- UX для вибору файлової системи й точки монтування.
- Окремий екран hardware evidence.
- Будь-який реальний disk APPLY: його навмисно вимкнено.
