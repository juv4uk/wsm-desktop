# Псевдографічний preview інсталятора

<!-- SPDX-License-Identifier: LicenseRef-Volnist -->

- Статус: **read-only preview; APPLY вимкнено**
- Код: [`wsm_install/tui.py`](../wsm_install/tui.py)
- Тести: `tests/test_tui.py`

## Призначення

TUI — навігаційна оболонка для консолі з екраном і клавіатурою, але без
графічного середовища. Він дозволяє вибрати диск і firmware, перевірити
ціль і показати план. Install callback відсутній.

Після preview інтерфейс прямо повідомляє:

- APPLY вимкнено;
- жодна команда розбиття/форматування/монтування не виконувалась;
- WSM **не встановлено**.

Якщо stdin/stdout не є TTY, CLI переходить на guided preview, а не запускає
напівпрацюючий екран.

## Чому без curses

Екран — це список рядків, а читання клавіш ін'єктоване. Це дає змогу перевіряти
навігацію, backspace, неправильний шлях і вихід на кожному кроці без справжнього
термінала.

## Межі

TUI не є інсталятором і не авторизує destructive операції. Повернення APPLY
потребуватиме окремого security review спільного backend-а; не можна додати
install callback у frontend як обхід preview-only межі.
