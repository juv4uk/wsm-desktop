# Псевдографічний інсталятор

- Статус: **read-only preview; APPLY вимкнено; у реальному терміналі не запускали**
- Код: [`wsm_install/tui.py`](../wsm_install/tui.py)
- Тести: `tests/test_tui.py` (12)

## Три входи, один бекенд

| Вхід | Кому | Вартість |
| --- | --- | --- |
| `--guided` (консоль) | послідовна лінія, скрипт, сліпий термінал | нуль |
| `--tui` (псевдографіка) | машина з екраном і клавіатурою, але без робочого столу | символи рамок |
| Calamares | машина, яка тягне Qt | Qt і KDE-стек |

Усі три викликають ті самі `partition.py`, `install_steps.py`, `executor.py`.

## Як виглядає

```
┌────────────────────────────────────────────────────────────┐
│ WSM install                                                │
├────────────────────────────────────────────────────────────┤
│                                                            │
│ Choose the disk to install onto:                           │
│                                                            │
│ > 1. /dev/nvme0n1       256 GiB                            │
│   2. /dev/sda           120 GiB  removable                 │
│                                                            │
│ ↑/↓ or j/k to move, Enter to choose, q to quit.            │
└────────────────────────────────────────────────────────────┘
```

Далі екран firmware (UEFI/BIOS), підтвердження шляху лише для preview та екран
результату планування. Етапу запису немає; TUI не має install callback.

## Чому не curses

`curses` є у стандартній бібліотеці, але тягне обробку можливостей термінала й
глобальний стан екрана, який важко тестувати і який ламається на послідовних
консолях.

Тут екран — це список рядків плюс читач клавіш. Обидва ін'єктовані, тому всі
12 тестів проходять без термінала: рамка, навігація з обертанням, backspace,
відмова при невірному шляху, вихід на кожному екрані.

## Що робить його безпечним

Диск обирає людина; введений шлях лише підтверджує ціль preview. Enter після
побудови плану не запускає запис. APPLY вимкнено, а успішний preview не
позначається як завершена інсталяція.

## Відкат на консоль

Якщо `stdin` або `stdout` не є терміналом (пайп, послідовна лінія без керування
курсором), `--tui` **не** малює зламаний екран, а переходить на консольний потік
і пише про це в stderr.

## Чого ще немає

- **Запуску в справжньому терміналі.** Жодного разу.
- **Реального APPLY.** TUI лише показує preview і не викликає disk executor.
- **Вибір файлової системи й точки монтування** на екрані: беруться типові.
- **Показу доказів заліза** окремим екраном — лише рядок `Hardware:` знизу.
- **Обробки вузьких терміналів**: ширина рамки фіксована (62), на 40 колонках
  рядки обріжуться.
