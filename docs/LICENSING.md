## Ліцензія проєкту — ВОЛЬНІСТЬ

Уся робота, створена для WSM Desktop у цьому репозиторії — код, конфігурації,
скрипти, тести й документація — поширюється під ліцензією **ВОЛЬНІСТЬ**.

Повний текст: [`LICENSE`](../LICENSE). Для машинного читання — той самий текст
у [`LICENSES/LicenseRef-Volnist.txt`](../LICENSES/LicenseRef-Volnist.txt) під
ідентифікатором `LicenseRef-Volnist` (SPDX не має стандартного коду для цієї
ліцензії, тому використовується власний `LicenseRef-`).

ВОЛЬНІСТЬ не є OSI-визнаною ліцензією. Це свідомий вибір автора, а не
недогляд: проєкт не претендує на сумісність зі стандартними ліцензійними
наборами, і ніщо в ньому не переліцензовує чужі роботи.

## Метадані пакетів GNU Guix

Власні Guix-пакети WSM використовують спільний об’єкт `wsm-license` з
модуля `(wsm licenses)`. Він передає Guix точну назву **ВОЛЬНІСТЬ**,
посилання `file://LICENSE` на текст у корені source tree пакета та коментар
`LicenseRef-Volnist`. Конструктор `license` є стандартним API закріпленої
версії Guix.

Це відображення авторської ліцензії в package metadata, а не її
перекласифікація. Воно не стверджує GPL, non-copyleft, OSI approval або FSDG
compatibility. У визначеннях власних пакетів не можна підміняти
`wsm-license` стандартним ідентифікатором лише для проходження перевірки.

## Правовласник

Оригінальні матеріали WSM Desktop належать авторам проєкту. Персональні дані
тут навмисно не вказані: публічний репозиторій не місце для особистих імені,
прізвища чи пошти, а для чинності ліцензії достатньо самого факту авторства.

Контакт — через GitHub: issues у цьому репозиторії. Хто саме є автором, видно
з історії комітів; жодних додаткових персональних даних для цього не потрібно.

## Сторонні компоненти

Ліцензія WSM Desktop не змінює ліцензій GNU Guix, Calamares, Nonguix, Linux,
драйверів, firmware або інших пакетів. Кожен сторонній компонент зберігає
власні умови, і його файли не переліцензовуються під ВОЛЬНІСТЬ.

У цьому репозиторії стороннього коду немає: `systems/*.scm` описують
конфігурацію Guix, але не містять скопійованого коду Guix.

Не включайте в ISO файл лише тому, що він завантажується з upstream-репозиторію.
Перевірте право на розповсюдження, вимоги до повідомлень, source offer та
можливі trademark restrictions — це вимога [ETHICS.md](ETHICS.md), і вона не
залежить від ліцензії проєкту.
