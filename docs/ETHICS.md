# Етичні принципи та сторонні компоненти

## Вільне програмне забезпечення — типовий шлях

WSM Free є базовим профілем. Він не повинен залежати від Nonguix, proprietary firmware або закритих драйверів.

Мета проєкту — не приховати компроміси, а дати користувачеві точну інформацію, щоб він міг прийняти свідоме рішення.

## Nonguix — окремий optional channel

Nonguix є незалежним каналом спільноти для Guix. Його README прямо описує обмеження та застереження щодо nonfree software і просить не просувати канал як офіційно рекомендований GNU Guix компонент.

WSM Desktop може документувати спосіб його підключення як опцію сумісності, але:
- не називає Nonguix частиною офіційного Guix;
- не вмикає канал у Free-профілі;
- не приховує nonfree статус пакетів;
- не вважає весь вміст каналу однаково ліцензованим;
- не перерозповсюджує firmware або blobs до перевірки умов їхніх ліцензій.

## Дозвіл на розповсюдження

Наявність пакета в сторонньому каналі не означає автоматичного права включити його у WSM ISO. Для кожного компонента, який планується розповсюджувати, потрібно зафіксувати:
- назву та точну версію;
- upstream URL і ревізію;
- ліцензію або умови використання;
- джерело бінарного файла;
- чи дозволяє ліцензія дзеркалювання та розповсюдження;
- чи потрібне окреме завантаження користувачем.

Якщо право на розповсюдження не підтверджено, компонент не включається до образу.

## Binary substitutes та довіра

Binary substitute server — це окремий постачальник бінарних артефактів. Його ключ підпису не додається автоматично лише тому, що сервер згадується в інструкції Nonguix.

Перед авторизацією ключа перевіряємо його походження через upstream-джерело та документуємо межу довіри. Не вставляємо ключі, токени або довільні URL у системні конфігурації без явного рішення.

## Інформація для користувача

Коли інсталятор пропонує Compatibility, він має пояснити:
- що саме додається;
- чому цей компонент може бути потрібний;
- чи є він вільним;
- які обмеження аудиту та безпеки він створює;
- чи буде він завантажений із мережі або включений до ISO.

## Товарні знаки та незалежність

GNU, GNU Guix, Nonguix та Calamares зберігають власні назви, логотипи й торговельні марки. WSM Desktop не використовує їх так, щоб створити враження офіційного схвалення, партнерства чи походження.
