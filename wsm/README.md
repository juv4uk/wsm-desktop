# WSM Guix channel modules

<!-- SPDX-License-Identifier: CC-BY-SA-4.0 -->

This directory is reserved for WSM-owned Guix channel modules, including packages, services, operating-system helpers, and profile transformations.

Do not copy packages from GNU Guix or Nonguix into this directory merely to create a local duplicate. Prefer upstream packages and contribute improvements upstream. A WSM package belongs here only when it is genuinely WSM-specific or an upstream contribution is not yet available.

Any package definition must include accurate source origin, version, hash, build system, inputs, and license metadata. Do not add proprietary binaries without explicit legal and ethical review.
